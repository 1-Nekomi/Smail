# Smail Qt/C++ 实现方案

## 产品与界面

独立桌面工具，Qt 6 Widgets + C++17。窗口分为邮箱设置、
收取规则、运行记录三个页签，底部提供开始/停止及运行状态。
QQ 预设 IMAP 993 / SMTP 465；自定义服务器支持隐式 TLS、密码/授权码登录。
Windows 授权码默认通过当前用户范围的 DPAPI 加密持久保存，JSON 配置不写授权码，
应用不内置加密密钥。其他平台暂只使用内存。先支持单账号，后续扩展 OAuth2。
关闭窗口时如托盘可用则最小化到托盘；托盘菜单可恢复窗口或退出。

## 目录与依赖

- `include/smail/`：公共接口及数据模型。
- `src/core/`：配置、MIME、规则、SQLite 状态、附件落盘。
- `CredentialStore`：以邮箱和 IMAP/SMTP 端点为范围保存 DPAPI 密文，支持读取、更新和删除；
  使用相同范围作为 DPAPI 附加熵，防止跨账号替换密文；损坏时提示重新输入，不降级为明文。
- `src/net/`：基于 QSslSocket 的 IMAP 与 SMTP 隐式 TLS 客户端。
- `src/app/`：后台收取线程、Widgets 主窗口、托盘与进程入口。
- `tests/qt/`：Qt Test 离线回归测试。
- `CMakeLists.txt`：Qt Core/Widgets/Network/Sql/Test，无额外第三方运行依赖。

## 数据流与一致性

后台线程每轮独立建立 IMAP TLS 会话 → SELECT INBOX → UIDVALIDITY →
首次建立 UID 基线 → 按 UID 顺序查询后续邮件 → RFC822.SIZE →
BODY.PEEK[] → MIME 与规则判断 → QSaveFile 原子落盘 →
SQLite 保存处理结果 → 可选 SMTP 自动回复 → STORE Seen → 提交进度 → UI/托盘通知。

以服务器、端口、账号组成邮箱键，UIDVALIDITY 与 UID 组成消息键；
新邮件按 UID 跟踪，避免手机先读导致遗漏。每次开始收取额外执行 UID SEARCH UNSEEN，
将启动前的未读 UID 合并进 SQLite 持久队列，再与新 UID 排序去重处理。
完成时在同一事务中移除队列项、单调推进基线；断线重试保留待办，UIDVALIDITY 隔离队列。
已存在处理记录不重复下载或回复；默认跳过首次连接之前的已读邮件。
勾选历史收取仅对尚未建立基线的账号生效。UIDVALIDITY 变化会重新建立基线。
筛选后单附件直接保存到目标目录，保留清理后的原文件名；冲突时添加 `(2)` 等编号。
SQLite 的 single_files 表在落盘前预留消息对应路径，崩溃重试复用该路径。
多附件落盘路径按消息键和附件编号稳定生成；SQLite 保存结果与待完成状态，
标记已读失败可以重试，不重复下载已保存附件。
SMTP 发送前记录 attempted；发送失败/超时记录 uncertain 且不自动重发，
避免崩溃导致重复自动回信。不声称 SMTP 恰好一次交付。

## 收取与安全规则

扩展名白名单（可选 MIME 白名单），任意类型需显式留空；
matching 保存匹配部分；strict 任一候选不匹配则整封拒收。
默认忽略内嵌图片，可开启；按此选项判断“有附件/无附件”，记录并标记已读。
ReplyPolicy 按处理结果互斥选择：成功保存附件 / 无附件 / 附件拒收，各有独立开关和文字。
成功回复只在落盘完成后决定；整封超限未解析则不回复。新开关默认关闭，旧配置兼容。
三类回复共用同一 attempted/sent/uncertain 持久化流程，不重复回信。
拒收表示客户端拒绝保存，非服务器投递退信。模板支持 `{reason}`、`{allowed_types}`、`{attachment_count}`。
禁止回复自动邮件、列表邮件、自己与 no-reply 发件人，避免循环。
只回复 From 中单个合法邮箱，不使用任意 Reply-To。
限制邮件/附件大小、MIME 深度和数量；清理文件名，避免路径逃逸与同名覆盖。
默认 TLS 证书校验，不提供跳过校验开关；授权码不进入日志。
不自动解压、不运行附件，不支持网盘/云附件链接或内容鉴真。

## 阶段与验证

1. 架构与 CMake 骨架（本文件）。
2. 配置、MIME、规则、状态与存储；离线测试。
3. TLS 邮件协议与收取状态机；协议解析测试。
4. UI、托盘、集成构建、离线验收和使用说明。

每阶段独立 Git 提交。真实邮箱发送/收取需要用户授权码，不能用离线测试冒充联调。

## 建议后续扩展

其他平台的系统凭据库、发件人白名单、归档规则与多账号优先；
随后支持 OAuth2、开机启动、杀毒接口。首版轮询间隔默认 60 秒，
网络故障退避到最多 15 分钟。电脑必须开机、联网且不休眠。
