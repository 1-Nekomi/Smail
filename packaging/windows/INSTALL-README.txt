Smail 邮件附件收取 0.1.2（Windows x64）

运行安装程序，按向导安装。安装仅作用于当前用户，不需要管理员权限。
默认位置：%LOCALAPPDATA%\Programs\Smail
可通过桌面或开始菜单快捷方式启动；Windows“已安装的应用”中可卸载。

首次运行填写邮箱地址、邮箱授权码和附件目录，点击“保存设置”或“开始收取”。
“收取规则 → 自动回复”可分别设置有附件（保存成功后）和无附件的回复文字，需勾选开启。
被拒收的附件使用独立的拒收回复，每封邮件最多自动回复一次。
默认加密保存授权码；默认只收取首次成功连接后的新邮件。
只有一个匹配附件时直接保存为文件；多个附件保存在邮件子目录中。
关闭窗口会继续在系统托盘运行；右键托盘图标选择“退出”可完全关闭。
更新或卸载前，请先完全退出 Smail。

卸载仅删除本安装包包含的程序文件及快捷方式。
已下载附件及 %LOCALAPPDATA%\Smail\Smail 下的配置、历史、加密授权码会保留。
如需删除已保存授权码，请在卸载前点击程序中的“忘记授权码”。
加密授权码通常绑定当前 Windows 用户和电脑，复制到其他电脑后需重新输入。

本安装包未进行代码签名，Windows 可能显示“未知发布者”提示。
请仅安装可信来源的副本，并可使用随包提供的 SHA256 文件核对完整性。
